How this works

Edit your puppet options and settings here — no coding needed.

Two kinds of category.
grid — a simple list of choices (Shoes, Extras, Colour).
steps — a step-by-step wizard (Nose = Shape → Size → Colour). You edit the dimensions; the app builds every combination for you, so you never hand-write hundreds of rows.

Adding a 3D model. Put your .glb in assets/models/ (or upload it to Shopify Files and copy the URL). For grid options, type the filename or URL in the Model box. For steps categories, name your file to match the pattern shown on that category and it will be picked up automatically.

Saving. Click Save options.json, then replace data/options.json with the downloaded file and reload the builder.
